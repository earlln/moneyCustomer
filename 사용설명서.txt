================================================================
  금전 대고객 작업 분류 - 배치 추론 및 학습 v1.8 (고성능 버전)
================================================================

[개요]
  CSV 파일의 작업 내용을 자동으로 분류하는 배치 처리 프로그램입니다.
  v1.8은 정확도를 0.9 이상으로 높이기 위해 최신 머신러닝 기법과 
  한국어 특화 전처리를 도입한 고성능 버전입니다.

[핵심 변경 사항]
  1. 형태소 분석 도입 (KoNLPy - Okt): 
     - 단순 띄어쓰기 기반이 아닌, '명사'만 정밀하게 추출하여 학습합니다.
     - 예: "금전적인 처리" -> "금전", "처리" (핵심 키워드만 남김)
  2. 전처리 강화: 특수문자, 숫자 제거 및 불용어 처리를 통해 노이즈를 제거했습니다.
  3. 모델 변경 (LightGBM): 
     - 랜덤 포레스트보다 한 단계 진화한 Gradient Boosting 모델을 사용하여 
       더 복잡한 패턴을 학습하고 정확도를 극대화했습니다.
  4. TF-IDF 확장: 특징 수를 10,000개로 확장하여 더 세밀한 단어 정보를 반영합니다.

[필수 설치 사항 (중요)]
  이 버전은 고성능 라이브러리를 사용하므로, 실행/컴파일 전 반드시 다음 설치가 필요합니다.

  1. Java 설치 (KoNLPy 작동 필수):
     - Oracle JDK 또는 OpenJDK 설치 필요. 설치 후 JAVA_HOME 환경 변수 설정이 필요할 수 있습니다.
  2. 필수 라이브러리 설치:
     - cmd창에서 다음 명령어를 실행하세요:
       pip install konlpy lightgbm

[파일 구성]
  - batch_predict.exe / .py : 고성능 추론 모듈
  - train_model.exe / .py : 고성능 학습 모듈
  - evaluate_model.exe / .py : 모델 성능 평가 도구 (v1.8 신규)
  - request_model.pkl : 학습된 분류 모델 (판단 뇌 역할)
  - request_vectorizer.pkl : 텍스트 벡터화기 (언어 번역기 역할)
  - features.json : 분류 설정 및 파일명 관리 파일
  - train_data.csv : 학습 데이터
  - train_log.txt : 학습 과정 기록 로그
  - 사용설명서.txt : 이 파일

[사용 방법]

  1. 입력 CSV 파일 준비
     - 파일명: features.json의 "files.input" 설정값 (기본: input.csv)
     - 컬럼: 제목, 설명, 개발책임 (features.json 기준)
     - 인코딩: UTF-8 또는 CP949

     예시 (input.csv):
     ┌──────────┬──────────────────┬──────────┐
     │ 작업의뢰명 │ 작업의뢰내용     │ 시스템명 │
     ├──────────┼──────────────────┼──────────┤
     │ 서버점검 │ 정기 보안 패치   │ 김철수   │
     │ 금전정산 │ 월말 금전 처리   │ 이영희   │
     └──────────┴──────────────────┴──────────┘

  2. 명령 프롬프트(cmd) 실행
     - 탐색기에서 폴더 주소창에 "cmd" 입력 후 엔터

  3. 실행 명령어

     기본 실행 (features.json 설정값 사용):
       batch_predict.exe

     일시적 파일 지정 (명령어 인자로 덮어쓰기):
       batch_predict.exe -i mydata.csv -o result.csv

     결과 미리보기:
       batch_predict.exe --show

     인코딩 지정 (한글 깨질 때):
       batch_predict.exe --encoding cp949

[출력 결과]
  features.json의 "files.output" 설정값 파일에 다음 컬럼이 추가됩니다:

  - prediction  : 예측 클래스 번호 (0, 1, 2, 3)
  - label       : 예측된 분류명
  - major_label : 주요작업 / 비주요작업
  - prob_0      : 비주요작업 확률 (0~1)
  - prob_1      : 금전작업 확률 (0~1)
  - prob_2      : 대고객작업 확률 (0~1)
  - prob_3      : 금전+대고객 확률 (0~1)
  - is_major    : 주요작업 여부 (True/False)

[분류 기준]
  0 = 비주요작업
  1 = 금전작업
  2 = 대고객작업
  3 = 금전+대고객 (둘 다)

  금전작업(1), 대고객작업(2), 금전+대고객(3) 중 하나라도
  확률이 50%(threshold) 이상이면 "주요작업"으로 분류됩니다.

[모델 재학습 및 성능 평가]

  1. 모델 재학습:
     - 학습 데이터 수정: features.json의 "files.train_data" 설정 파일을 수정합니다.
     - 학습 실행: train_model.exe를 실행합니다.
     - 로그 확인: train_log.txt에서 학습 과정과 성적표를 확인합니다.

  2. 모델 성능 평가 (evaluate_model.exe):
     - 용도: 학습 완료 후, 별도의 데이터셋으로 모델의 실제 실력을 검증합니다.
     - 실행 방법: evaluate_model.exe를 실행합니다.
     - 기준 데이터: features.json의 "files.train_data"에 지정된 파일을 읽어 정확도를 계산합니다.
     - 결과 확인: 최종 정확도(Accuracy)와 세부 분류 리포트, 혼동 행렬을 출력합니다.

[설정 파일 (features.json) 상세 설명]

  이 파일은 프로그램의 동작 방식을 결정하는 핵심 설정 파일입니다. 메모장으로 열어 수정할 수 있습니다.

  1. 기본 정보
     - project_name: 프로젝트의 이름입니다. 주로 API 서버의 타이틀이나 관리용 식별자로 사용됩니다.
     - version: 현재 프로그램의 버전입니다.

  2. 데이터 컬럼 설정 (매우 중요)
     - input_columns: 분석에 사용할 텍스트 컬럼들의 리스트입니다. (예: ["작업의뢰명", "작업의뢰내용", "시스템명"])
       ※ 주의: 학습 데이터와 추론 데이터(input.csv)의 헤더 이름이 이 설정과 정확히 일치해야 합니다.
     - target_column: 학습 데이터에서 정답(Label)이 들어있는 컬럼명입니다. (예: "금전대고객구분")
       ※ 추론 시에는 사용되지 않으며, 학습 시에만 정답지를 찾는 용도로 사용됩니다.

  3. 분류 로직 설정
     - class_labels: 클래스 번호(0,1,2,3)에 대응하는 실제 이름입니다. 출력 결과의 'label' 컬럼에 표시됩니다.
     - major_classes: "주요작업"으로 간주할 클래스 번호들의 리스트입니다. (예: [1, 2, 3])
     - threshold: 주요작업 판단 기준 확률입니다. (0.0 ~ 1.0)
       예: 0.5로 설정 시, major_classes 중 어느 하나라도 확률이 50% 이상이면 "주요작업"으로 판정합니다.

  4. 파일명 관리 (files 섹션)
     - train_data: 학습 및 평가에 사용할 CSV 파일명입니다.
     - input: 추론 시 사용할 기본 입력 파일명입니다. (예: "input.csv")
     - output: 추론 결과가 저장될 기본 출력 파일명입니다. (예: "output.csv")
     - model: 저장/로드할 모델 파일명입니다. (예: "request_model.pkl")
     - vectorizer: 저장/로드할 벡터라이저 파일명입니다. (예: "request_vectorizer.pkl")

[모델 성능 평가 상세 알고리즘]

  evaluate_model.exe는 단순히 정답 개수를 세는 것을 넘어, 다각도에서 모델의 신뢰성을 검증합니다.

  1. 평가 프로세스:
     - [로드] features.json 설정에 따라 모델(.pkl)과 벡터라이저(.pkl)를 메모리에 복원합니다.
     - [전처리] 평가 대상 CSV의 텍스트를 학습 때와 동일하게 '명사 추출' 및 '특수문자 제거' 처리합니다.
     - [예측] 복원된 모델을 통해 각 행의 클래스를 예측합니다.
     - [비교] 예측값과 CSV의 실제 정답을 일대일로 대조하여 성능 지표를 산출합니다.

  2. 핵심 평가 지표:
     - 정확도(Accuracy): 전체 데이터 중 정답을 맞힌 비율입니다. (가장 직관적이지만 데이터 불균형에 취약함)
     - 정밀도(Precision): 모델이 'A'라고 예측한 것 중 실제로 'A'인 비율입니다. (오답을 줄이는 능력)
     - 재현율(Recall): 실제 'A'인 데이터 중 모델이 'A'라고 찾아낸 비율입니다. (놓치지 않는 능력)
     - F1-Score: 정밀도와 재현율의 조화 평균입니다. 데이터가 불균형할 때 가장 객관적인 성능 지표입니다.

  3. 혼동 행렬 (Confusion Matrix):
     - 실제 정답과 예측 정답을 교차 표로 나타낸 행렬입니다.
     - 어떤 클래스를 어떤 클래스로 착각하고 있는지(예: 금전작업 $\rightarrow$ 대고객작업) 구체적인 오답 패턴을 분석하여 모델의 취약점을 파악하는 데 사용됩니다.
