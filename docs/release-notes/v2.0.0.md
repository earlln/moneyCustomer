# v2.0.0 — Java 없이 실행 / Windows exe 배포

v1.8 의 가장 큰 제약이던 **Java(JVM) 의존성을 완전히 제거**하고,
파이썬조차 설치되지 않은 Windows PC 에서 바로 실행할 수 있도록
**exe 로 컴파일해 배포**하는 릴리스입니다.

## 다운로드 — stand-alone PC 용

`MoneyCustomer_v2.0.0_win64.zip` 을 내려받아 **`C:\MoneyCustomer` 처럼 짧은 경로**에
압축을 푼 뒤 `자체점검.bat` 을 더블클릭하면 설치 확인이 끝납니다.

**파이썬 · Java · 인터넷 · 관리자 권한 모두 필요 없습니다.**
파이썬 런타임과 kiwipiepy 형태소 사전이 `_internal/` 안에 함께 들어 있습니다.
압축 약 250MB, 해제 후 약 400MB 입니다.

- `_internal/` 은 exe 와 같은 위치에 있어야 합니다. exe 만 복사하면 실행되지 않습니다.
- `C:\Program Files` 아래는 피하세요. 결과 CSV·로그를 프로그램 폴더에 기록합니다.
- 코드 서명이 없어 백신·SmartScreen 경고가 뜰 수 있습니다.
- 대상 OS 는 64비트 Windows 10 이상입니다.

## 주요 변경 사항

### 1. Java(JVM) 의존성 제거 ★

v1.8 은 KoNLPy 의 `Okt` 형태소 분석기를 사용했고, 이는 JPype 를 통해 JVM 위에서
동작하므로 JDK 설치와 `JAVA_HOME` 설정이 필수였습니다.

v2.0.0 은 C++ 로 구현된 `kiwipiepy` 로 교체했습니다. 새로 추가된
`korean_tokenizer.py` 가 토크나이저를 추상화하며 두 가지 백엔드를 제공합니다.

| backend | 구현 | Java | 정확도 |
|---|---|---|---|
| `kiwi` (기본) | `kiwipiepy` (C++) | 불필요 | 높음 |
| `regex` | 순수 파이썬 규칙 기반 | 불필요 | 낮음 (최후 수단) |

릴리스 워크플로는 매 빌드마다 **파이썬을 `PATH` 에서 완전히 제거하고** `JAVA_HOME` 등
관련 환경변수를 비운 뒤, 저장소 밖의 별도 폴더로 패키지를 복사해 세 exe 를 모두
실행합니다. 작업 디렉터리도 exe 폴더 바깥에 두어 경로 해석까지 함께 검증합니다.
번들에 파이썬 런타임 DLL 과 MSVC 런타임(`vcruntime140.dll`, `msvcp140.dll`)이
들어 있는지, `.jar` · JVM · JPype 흔적이 남아 있지 않은지도 자동으로 확인합니다.

### 2. Windows exe 3종 배포 (파이썬 미설치 PC 대상)

`batch_predict.exe` · `train_model.exe` · `evaluate_model.exe`
그리고 설치 직후 동작을 확인하는 `자체점검.bat`

세 프로그램은 scikit-learn · LightGBM · kiwipiepy 형태소 사전 등 350MB 가 넘는
동일한 의존성을 쓰기 때문에, 각각 따로 묶으면 배포 용량이 1GB 를 넘습니다.
`MoneyCustomer.spec` 은 하나의 번들에 세 실행 파일을 만들어 런타임을 공유시키고,
`mc_entry.py` 가 실행 파일 이름으로 어떤 모듈을 실행할지 분기합니다.

### 3. `evaluate_model` 실행 오류 수정

v1.8 의 `evaluate_model.py` 는 소스 오타 3곳(`file_//config`, `csv_//file_name`,
`y_//true`) 때문에 실행 즉시 `NameError` 로 중단되었습니다. v2.0.0 에서 수정했습니다.

### 4. 정확도 측정 방식 정정 ★

v1.8 문서의 **96.58%** 는 `evaluate_model.py` 가 *학습에 사용한 데이터를 그대로
평가에 사용*해서 나온 값으로, 실제 성능보다 크게 부풀려져 있었습니다.
학습에 쓰이지 않은 검증 구간(20%, 4,000행)에서 다시 측정한 결과는 다음과 같습니다.

| 측정 방식 | v1.8 모델 | v2.0.0 모델 |
|---|---|---|
| 전체 20,000행 (학습 데이터 포함 · 과대평가) | 0.9658 | 0.9769 |
| 검증 4,000행 (학습에 미사용 · **실제 성능**) | **0.8695 (86.95%)** | **0.8975 (89.75%)** |

즉 v2.0.0 은 Java 의존성을 없애면서 실제 정확도도 함께 끌어올렸습니다.
`evaluate_model` 은 이제 검증 구간 수치를 먼저 보여주고, 전체 데이터 기준 수치는
"참고용(과대평가)" 라고 명시해 함께 출력합니다.

### 5. 전처리 개선 — 영문·숫자 보존

v1.8 은 전처리에서 한글만 남겨 시스템명의 영문 약어(`HI-sPortal`, `DB`, `PUSH` 등)가
모두 버려졌습니다. v2.0.0 은 영문·숫자도 소문자로 정규화해 학습에 활용합니다.
(`features.json` 의 `tokenizer.keep_latin` 으로 끌 수 있습니다.)

### 6. 설정 확장

`features.json` 에 `tokenizer`, `vectorizer`, `model_params` 섹션이 추가되어
재코딩 없이 TF-IDF 특징 수, n-gram 범위, LightGBM 하이퍼파라미터를 조정할 수 있습니다.

벡터라이저 기본값(15,000 특징 · 1~2gram)은 v1.8 과 동일하게 유지했습니다.
30,000 · 50,000 특징도 실측했으나 과적합만 늘고 검증 정확도는 오히려 떨어져
(각각 0.8882) 기본값을 바꾸지 않았습니다. 즉 이번 정확도 향상은 특징 수가 아니라
**토크나이저 교체와 영문·숫자 보존**에서 나온 것입니다.

### 7. 학습 산출물 추적 (`model_meta.json`)

학습 시각, 토크나이저 설정, 라이브러리 버전, 성능 지표를 기록합니다.
추론·평가 시 현재 설정과 비교해 다르면 경고를 출력하므로,
"설정만 바꾸고 재학습을 잊어 정확도가 떨어지는" 사고를 방지합니다.

### 8. 운영 편의성

- **인코딩 자동 판별** — UTF-8 / UTF-8-SIG / CP949 / EUC-KR 을 순서대로 시도합니다.
- **`--no-pause`** — "Enter 키를 누르세요" 대기를 생략해 배치 스케줄러에서 호출 가능합니다.
- **종료 코드 구분** — 0 정상 / 2 설정·파일 오류 / 1 내부 오류.
- **오류 메시지 개선** — 컬럼 불일치 시 CSV 의 실제 컬럼 목록을 함께 출력합니다.
- **결과 요약 강화** — 클래스별 예측 건수를 함께 출력합니다.

## 마이그레이션 (v1.8 → v2.0.0)

1. `pip uninstall konlpy` (Java 설치도 더 이상 필요 없습니다)
2. `pip install -r requirements.txt`
3. `features.json` 을 v2.0.0 것으로 교체 — `tokenizer` 섹션이 필요합니다.
4. v1.8 의 `.pkl` 은 Okt 토큰 기준이므로 **호환되지 않습니다.**
   이 릴리스에 포함된 `.pkl` 을 쓰거나 `train_model` 로 재학습하세요.

CLI 옵션(`-i`, `-o`, `--show`, `--encoding`)과 출력 CSV 컬럼 구성은 v1.8 과 동일합니다.

## 알려진 제약

- Windows `.exe` 는 Windows 에서만 빌드할 수 있습니다 (PyInstaller 는 크로스 컴파일
  미지원). 저장소의 **Actions → Release** 워크플로가 `windows-latest` 에서 빌드합니다.
- `regex` 백엔드는 의존성이 전혀 없는 대신 정확도가 눈에 띄게 낮습니다.
  `kiwipiepy` 설치가 불가능한 환경에서만 사용하세요.
