# v1.8.0 — 최초 공개 (KoNLPy Okt + LightGBM)

기존에 로컬에서 관리하던 **금전 대고객 작업 분류 v1.8** 패키지를 저장소에 그대로 등록한 릴리스입니다.
전달받은 압축 파일의 내용을 수정 없이 보존하는 것이 목적이며, 개선 사항은 v2.0.0 에서 다룹니다.

## 구성

| 파일 | 설명 |
|---|---|
| `batch_predict.py` | CSV 배치 추론 |
| `train_model.py` | TF-IDF(word 1~2gram, 15,000) + LightGBM 학습 |
| `evaluate_model.py` | 정확도 · 분류 리포트 · 혼동 행렬 평가 |
| `features.json` | 입력 컬럼 · threshold · 파일명 설정 |
| `request_model.pkl` / `request_vectorizer.pkl` | 학습 완료 산출물 |
| `train_20260527.csv` | 학습 데이터 20,000행 (CP949) |
| `사용설명서.txt` | 상세 사용 설명서 |
| `evaluate result.txt` | v1.8 평가 실행 결과 |
| `Text_Classification_v1.8.pptx` | 프로젝트 설명 자료 |

## 분류 기준

`0` 비주요작업 · `1` 금전작업 · `2` 대고객작업 · `3` 금전+대고객
→ 1·2·3 중 하나라도 확률이 `threshold`(0.5) 이상이면 **주요작업**.

## 실행 요건

- **Java(JDK/JRE) 필수** — KoNLPy `Okt` 형태소 분석기가 JVM 위에서 동작합니다.
- `pip install pandas scikit-learn lightgbm joblib konlpy`

## 알려진 이슈

이 릴리스는 전달받은 원본을 보존하기 위해 아래 문제를 **수정하지 않았습니다**.
모두 v2.0.0 에서 해결됩니다.

1. **`evaluate_model.py` 실행 불가** — 3개 라인에 오타(`file_//config`, `csv_//file_name`, `y_//true`)가
   있어 실행 시 `NameError` 로 중단됩니다.
2. **정확도 96.58% 는 과대평가된 값** — `evaluate_model.py` 가 학습에 사용한 데이터를 그대로
   평가에 사용합니다. 학습에 쓰이지 않은 검증 구간에서 다시 측정하면 실제 정확도는
   **86.95%** 입니다.
3. **Java 의존성** — JVM 이 없는 환경에서는 실행할 수 없습니다.
4. **영문 정보 소실** — 전처리에서 한글만 남기므로 시스템명의 영문 약어(`HI-sPortal`, `DB` 등)가
   모두 버려집니다.
